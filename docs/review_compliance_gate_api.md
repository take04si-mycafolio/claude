# 口コミ承認制＋薬機法ゲート API仕様（アプリ側実装ガイド）

2026-07-30 導入。対象エンドポイント:

- `POST /api/reviews/`（口コミ投稿）
- `POST /api/products/{id}/use-logs/`（使用記録投稿）

## 変更点1: 投稿は承認制になった

- 投稿成功時(201)の `is_approved` は常に `false` で返る。
- 運営が管理画面で内容確認・承認すると商品ページに掲載される。
- 商品の口コミ一覧 `GET /api/products/{id}/reviews/` は従来どおり承認済みのみ返す
  （＝投稿直後の自分の口コミは載らない）。
- 自分の投稿一覧 `GET /api/reviews/my/` には承認待ちも含まれ、`is_approved` で
  判別できる。

### アプリ側の推奨UI
- 投稿成功時:「投稿ありがとうございます。内容を確認のうえ掲載されます。」
- マイページの投稿一覧: `is_approved: false` の口コミに「確認中」バッジを表示。

## 変更点2: 投稿時に薬機法・景表法ゲートが入った

タイトル・本文に掲載できない表現（効果の断定・「治る」「最強」「絶対」など）が
含まれると **400** で以下を返す。従来の 400（重複投稿・商品不正など）と同様に
`detail` を持つが、`compliance` オブジェクトが付くのが特徴。

```json
{
  "detail": "掲載できない表現が含まれています。指摘箇所を修正して再投稿してください。",
  "compliance": {
    "hint": "「私の場合は〜でした」「〜な気がします」のように、あくまで個人の感想として書いていただくと掲載しやすくなります。",
    "findings": [
      {
        "field": "body",
        "severity": "CRITICAL",
        "headline": "体への効果・変化を断定する表現は、薬機法の関係で掲載できません",
        "match": "シミが消え",
        "start": 12,
        "end": 17,
        "reason": "シミ・シワ・たるみが「消える・治る」といった断定は書けません。",
        "example": "肌が明るく見えるようになった気がします / メイクのりが良くなりました"
      }
    ],
    "suggested_title": null,
    "suggested_body": "…(全文の言い換え案。作れない場合は null)…"
  }
}
```

### フィールドの意味
| キー | 説明 |
|---|---|
| `field` | `title` / `body` のどちらで検出されたか |
| `severity` | `CRITICAL`(薬機法:高) / `HIGH`(断定表現) / `KEIHYO`(景表法) / `SAFETY`(安全性断定) |
| `headline` | カテゴリの見出し(そのまま表示可能な平易な説明) |
| `match` | 検出された文字列そのもの |
| `start` / `end` | 該当フィールド内の文字位置(0始まり、`text[start:end] == match`)。入力欄のハイライトに使える |
| `reason` | なぜ掲載できないかの説明(表示用) |
| `example` | 言い換え例(表示用) |
| `suggested_title` / `suggested_body` | 全該当箇所を機械置換できた場合のみ、言い換え済み全文。ワンタップで入力欄へ反映する用途を想定。作れない場合は `null` |

### アプリ側の推奨UI
1. 400 かつ `compliance` があれば専用の指摘画面/シートを表示。
2. `findings` を1件ずつ「どこ(タイトル/本文)・該当表現・理由・言い換え例」で列挙。
3. `suggested_body` が非null なら「この言い換えを反映する」ボタンで本文入力欄を
   置き換え(反映後もユーザーが編集・確認してから再投稿)。
4. `hint` は指摘リストの上に常時表示。

## サーバ側実装(参考)
- ルール定義: `apps/products/management/commands/yakkihou_lint.py` の `RULES`（記事リンタと共通）
- ゲート本体: `apps/reviews/compliance.py`（理由・言い換え例・自動置換文の生成）
- Web(PC版)フォームも同一ルールで同時にゲート化済み。
